CS2 Chat Translator - Portable (Windows)
=========================================

START
  1. Unzip the whole folder anywhere (do not run it from inside the zip file).
  2. Double-click start.bat. Your browser opens the app.
  No installation and no Node.js are needed: a runtime is included in the "runtime" folder.

FIRST-TIME SETUP FOR CS2 (Settings -> CS2 -> First-time setup)
  - Steam launch option: -condebug
  - In the CS2 console, paste the bind command shown in the app.

YOUR DATA
  Settings and your encrypted Gemini API key are stored in %APPDATA%\cs2-chat-translator,
  not in this folder. Sharing this folder does not share your key.
